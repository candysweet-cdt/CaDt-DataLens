# CaDt-DataLens 隐私协议

最后更新：2026-11-09  
适用版本：CaDt-DataLens v1.0.0

CandySweet 尊重并保护用户隐私。本协议说明 CaDt-DataLens（以下简称“本软件”）如何处理与您有关的信息。核心原则是：**文件在本机处理，我们不上传、不收集您的文件与使用数据。**

## 1. 我们收集的信息

1.1 本软件不需要注册账号，不收集姓名、手机号、邮箱、设备标识或其他可识别个人身份的信息。

1.2 本软件不包含统计、埋点、广告或崩溃上报组件，不会自动上传您的使用记录、文件内容或文件路径。

1.3 您通过“反馈”入口主动打开 Gitee 问题页面时，您在页面上提交的内容由您自行决定，并受 Gitee 的隐私政策约束。

## 2. 本地数据

2.1 本软件在本机保存以下数据，均不会自动上传：

- 界面设置（主题、字体、布局、视图偏好等）保存在 WebView2 本地存储中；
- 后端配置（打开方式、插件目录模式、开发者模式等）保存在 `config.json`；
- 插件（当选择应用数据目录模式时）与运行日志保存在应用数据目录。

2.2 应用数据默认位于：`%APPDATA%\CandySweet\CaDt-DataLens`。日志仅保留最近若干次运行，可在设置中查看日志目录并自行删除。

2.3 错误与警告日志可能包含出错的本地文件路径、错误文本与程序版本信息，仅保存在本机，用于排查问题；开发者模式会额外记录调试信息。

## 3. 网络请求

本软件仅在以下功能被您主动使用时发起网络请求：

- **检查更新**：访问 Gitee API 获取本软件的发布版本信息。请求仅包含程序名称与版本号作为标识，不包含文件内容或个人信息。
- **插件市场**：访问 Gitee API 获取公开插件仓库列表与插件清单。
- **从仓库安装插件**：使用系统中的 Git 从您指定的仓库地址克隆插件。
- **打开发布页、仓库、问题反馈等链接**：交由系统默认浏览器打开。
- **Markdown 预览**：文档中引用的本地图片通过本机读取；若文档包含外链图片或其他网络资源，预览时可能由 WebView2 直接加载这些资源。

上述网络请求会向 Gitee 及相关服务提供方传输建立连接所必需的信息（如 IP 地址、User-Agent），其处理方式适用对应服务提供方的隐私政策。

## 4. 第三方插件

4.1 第三方插件可能拥有独立的网络访问、文件访问或数据收集行为，这类行为由插件作者负责，不在本协议的控制范围内。

4.2 请仅安装来源可信的插件。您可以在插件目录中查看、禁用或删除插件。

## 5. 数据安全与保留

5.1 本软件不会将您的文件或配置备份至云端；数据的保存位置与保留时长由您自行管理。

5.2 卸载本软件不会自动删除应用数据目录。如需彻底清理，请在卸载后手动删除 `%APPDATA%\CandySweet\CaDt-DataLens` 目录。

## 6. 未成年人保护

本软件是本地数据查看工具，不面向未成年人收集任何个人信息。未成年人应在监护人指导下使用。

## 7. 协议更新

我们可能随软件版本更新调整本协议。更新后的协议将通过软件内文档或发布页面提供，自发布之日起生效。

如对本协议或隐私保护有任何疑问，可通过以下方式联系我们：

- 问题反馈：https://gitee.com/candysweet-cdt/CaDt-DataLens/issues
