# 仓库目录结构与文件职责

> 本文件从 `AGENTS.md` 的「目录结构」章节外迁而来，记录当前代码库的逐文件/逐包职责、沿革与暗约束，供按需查阅（不随每轮上下文注入）。
>
> **查阅顺序**：认知索引开启时，优先用 `cognition_read` 按路径 / 标签 / 关键词查条目（索引默认关）；本文件作为索引未启用时的保底导航，随大结构调整时更新。
>
> 与 `docs/finished-plans/go-layout.md` 的区别：后者是 Go 包下沉的**方案与沿革**，本文件是**当前仓库的实际目录地图与文件职责**。

> 根目录是扁平 Go 包 `main`，没有顶层 `src/`。

## Go 后端（仓库根）
