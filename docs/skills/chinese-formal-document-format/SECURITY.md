# 安全与数据流

## 默认行为

中文正式文档排版默认在本地完成：

- 不上传用户 DOCX；
- 不读取远程模板；
- 不发送 telemetry；
- 不包含云端密钥；
- 原始 DOCX 只读，输出始终写入新文件。

## 文档处理

排版脚本在内存中读取 DOCX 的段落、表格、页眉页脚和关系结构。保存前会比较源文件与输出文件的内容签名；内容或结构发生变化时停止。

预览脚本只调用本机字体和本地渲染器。字体文件不会随 Skill 分发。

## 网络边界

核心排版、核验和测试不依赖网络。安装、更新和下载 Release 时由 Git、`skills` 安装器或浏览器发起网络请求。

## 文件安全

建议：

- 处理敏感材料时在本机运行；
- 外发前检查作者、修订记录、批注和隐藏元数据；
- 不要把未脱敏的单位模板或真实材料提交到 Issue；
- 报告安全问题时不附带包含个人或组织信息的原始 DOCX。

## 报告问题

如果发现内容完整性绕过、路径覆盖、恶意 DOCX 处理异常或意外网络请求，请在 GitHub Issue 中描述最小复现步骤，并移除真实文档中的敏感信息。
