# 保守排版规则

核心原则：

> 只改版式，不改文字。

英文 `conservative-rules.md` 是 Agent 执行依据；本文件面向中文用户解释边界。

## 可以修改

- 字体、字号、字重；
- 对齐、缩进和段落间距；
- 行距；
- 页面尺寸和页边距；
- 表格字体、边框、对齐和列宽；
- 标题层级对应的字体。

## 不可以修改

### 文字

- 不增加、不删除文字；
- 不润色、不扩写、不压缩；
- 不修正错别字；
- 不统一术语；
- 不改主体名称。

### 数字和日期

- 不改数字格式；
- 不把汉字数字改成阿拉伯数字；
- 不自动给日期补零；
- 发现日期或数字前后不一致时，只提醒。

### 标点

- 不把 `1、` 改成 `1.`；
- 不替换引号；
- 不增删顿号、逗号或句号。

### 结构

- 不拆段、不并段、不调换顺序；
- 不新增标题；
- 不新增目录、页码、页眉、页脚；
- 不新增表格、图片、附件或结束语；
- 不擅自拆分或合并表格单元格。

## 原文强调

正文中的局部加粗、斜体和下划线属于作者强调，应尽量保留。只有标题层级明确要求改变字重时，才调整标题字重。

## 结构歧义

遇到下面情况应暂停并询问：

- 一行既可能是标题，也可能是正文数据；
- 编号很可能是在写正文而不是分级标题；
- 同一行同时有标题和正文，且包含超链接、域或批注；
- 文种判断会改变用户期望的版式；
- 报告和请示语言混用。

不能静默猜测，也不能为了“排得整齐”自行拆段。

## 标题与编号正文

- `1. 完成情况`：短标签，可按三级标题；
- `1. 由市场部牵头，于10月25日前完成任务。`：完整句子，按正文；
- `（一）标题。正文……`：可拆成楷体标题句和仿宋正文；
- `（一）2026年前三季度收入完成年度预算的78.6%。`：完整陈述，按正文。

## 内容问题

发现下面问题只提醒：

- 日期书写不统一；
- 报告夹带请示事项；
- 同一数字前后不一致；
- 落款与标题主体不一致；
- 会议纪要用命令式或第一人称；
- 函件语气过于命令或过于卑微。

提醒必须和排版结果分开，不能顺手改掉。
