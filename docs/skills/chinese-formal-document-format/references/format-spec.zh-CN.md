# 默认版式参考

这是中文正式文档的默认参考配置。它使用与 GB/T 9704-2012 相关的常见做法，但不声称所有单位都必须采用同一标准。目标单位的现行模板和制度优先。

可执行配置以 `profiles/default.json` 为准。本文件用于向中文用户解释参数；英文 `format-spec.md` 是技术原文件。

## 页面

| 项目 | 数值 |
|---|---|
| 纸张 | A4，210 × 297 mm |
| 上边距 | 37 mm |
| 下边距 | 35 mm |
| 左边距 | 28 mm |
| 右边距 | 26 mm |
| 正文行距 | 固定值 28 pt |
| 标准版面 | 每页 22 行、每行约 28 字 |

单位换算：

- 1 英寸 = 25.4 mm = 1440 DXA = 72 pt；
- 1 mm ≈ 56.69 DXA；
- OOXML 中 1 pt = 20 个 `w:line` 单位。

默认使用二号标题、三号正文和标题、四号表格内容。

## 标题

- 字体：方正小标宋简体；
- 字号：22 pt；
- 对齐：居中；
- 段前/段后：24 pt；
- 首行缩进：无。

字体缺失时，不要悄悄修改 DOCX 中的字体名称。是否替换为本单位允许的字体，由用户确认。

## 主送机关

- 字体：仿宋_GB2312，16 pt；
- 左对齐、顶格；
- 以全角冒号 `：` 结尾。

会议纪要通常不写主送机关。

## 正文

- 字体：仿宋_GB2312，16 pt；
- 两端对齐；
- 固定行距 28 pt；
- 首行缩进 2 字符；
- 同时写入 `firstLineChars="200"` 和 `firstLine="640"`；
- 原文中的局部加粗、斜体和下划线作为作者强调保留。

## 标题层级

### 一级：`一、`

- 黑体，16 pt；
- 首行缩进 2 字符；
- 两端对齐。

### 二级：`（一）`

- 楷体_GB2312，16 pt；
- 首行缩进 2 字符。

同一段出现“标题句。正文……”时，拆成两个 run：

- 到第一个句号为止的标题句使用楷体；
- 后面的正文使用仿宋。

### 三级：`1.`

- 只有短标签式段落才使用三级标题样式；
- 字体仿宋_GB2312，16 pt，加粗。

完整句子式编号属于正文，例如：

> `1. 由市场部牵头，于10月25日前完成任务。`

这种段落保持仿宋、常规字重。不能仅凭编号判断标题。

### 四级：`（1）`

- 字体仿宋_GB2312，16 pt，常规字重；
- 完整句子同样按正文处理。

### 四级以后

`①`、`a)` 等更深层级默认保持仿宋常规。如果层级继续加深，应先由用户判断内容结构是否需要重排。

## 落款与日期

落款：

- 仿宋_GB2312，16 pt；
- 右对齐；
- 右缩进 2 字符；
- 段前约 30 pt。

日期：

- 仿宋_GB2312，16 pt；
- 右对齐；
- 右缩进 4 字符；
- 使用 `2026年5月13日` 形式；规范化补零必须经用户确认。

## 附件与附注

- 附件说明位于正文后、落款前，仿宋 16 pt，左缩进 2 字符；
- 附注位于日期后，仿宋 16 pt，左缩进 2 字符；
- 不自动添加附件或联系人信息。

## 表格

- 表题：仿宋_GB2312，16 pt，加粗，居中，无首行缩进；
- 表头：黑体，14 pt；
- 表体：仿宋_GB2312，14 pt；
- 单元格文字水平、垂直居中；
- 单元格行距为单倍，不使用正文的固定 28 pt；
- 表格使用统一细边框；
- 列宽总和占满可用版心，关闭自动适应；
- 默认重复表头行；
- 单元格四周保留留白。

## Word 样式映射

| 内容 | Word 样式 |
|---|---|
| 标题 | `Title` |
| 正文 | `Normal` 并覆盖字体、行距和缩进 |
| 一级标题 | `Heading1` |
| 二级标题 | `Heading2` |
| 三级标题 | `Heading3` |
| 四级标题 | `Heading4` |

OOXML 中样式名和样式 ID 可能不同，例如显示名 `Heading 1` 对应 ID `Heading1`。
