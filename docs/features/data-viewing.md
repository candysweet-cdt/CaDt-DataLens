# 数据查看与开发

> 本文档从 [README.md](../../README.md) 外迁，收录对应主题的完整功能细节。
> 项目总览与快速上手见 README。

## 格式与视图

- 结构化格式：JSON / JSONC / JSON5、JSONL / NDJSON、YAML / YML、XML / SVG、CSV / TSV、TOML、INI / Properties。
- JSONL 按行解析为数组显示，树视图编辑后仍按“一行一个 JSON 值”保存。
- 文本格式：txt、log、conf 默认以文本视图打开；html、css、js、ts、py、go、java、sql 等代码类扩展名默认代码视图，可在视图菜单切换。HTML 另有**预览**（iframe 渲染，默认关闭、需手动切换）与**分屏**视图。
- Markdown 文件默认打开预览：标题、列表、表格、引用、代码块和 KaTeX 行内/块级公式；代码块按当前主题高亮，行号可在设置中开启（默认关闭）。预览只读，可切回代码/文本视图编辑。原始 HTML 不执行，外部链接交给系统浏览器打开。
- 多种视图：
  - **结构视图**（左侧工具条按钮 / `Alt+7`）：读取当前文件结构，按层级显示 Markdown 标题、HTML/XML 标签树、Python/JS/TS/Go/Java/C/C++/Rust/PHP/Ruby/Lua 的类、方法、函数、变量，以及 JSON/YAML/TOML/INI 的键层级；单击条目跳到对应源代码行。支持全部折叠/展开、刷新、随编辑自动更新，并高亮光标所在结构项；签名/标签超出侧边栏宽度时显示横向滚动条，完整显示而不省略。面板也会跟着内容区走：只有文件时显示文件结构；只有 AI 助手时显示**当前会话的结构**（按轮列出的用户消息定位条，点一下跳到那条消息，并随滚动高亮当前所处的一轮）；两者同时存在时默认文件结构，面板标题旁的图标可在两者间切换。
  - **树视图**：展开/收起节点，直接编辑键和值；右键节点可展开/折叠该节点、全部展开/收起、复制树。
  - **代码视图**：Ace 编辑器，带行号、语法高亮、括号匹配。按扩展名启用 YAML、XML/SVG、JS/TS、Python、Markdown、HTML/CSS、Shell/PowerShell/Batch、Go/Java/Kotlin/Lua/SQL、TOML/INI/Properties 等语法模式。折叠区显示 `...` 占位符：花括号块折叠后行尾保留 `{` 与 `}`，渲染成 `{...}`；`import ( )` 这类圆括号块把括号本体一起折进去，显示成 `import ...`。hover 折叠行会弹出带原始行号和语法高亮的完整折叠内容，树视图不显示该 hover 预览。右下角显示当前 `行:列`，点击或 `Ctrl+G` 可跳转。
  - **文本视图**：所有文件都可切换到纯文本编辑框，使用 Consolas 等宽字体和窄边距，接近 Windows 记事本的显示效果；适合看原始内容和最简单的文本修改。图片/二进制文件以只读十六进制文本显示。右下角显示当前 `行:列`，点击或 `Ctrl+G` 可跳转。
  - **预览**（Markdown / HTML）：Markdown 为只读渲染，支持代码块语法高亮和数学公式；HTML 用 iframe 渲染真实页面（sandbox 隔离，`<base>` 指向文件所在目录，同目录的相对样式 / 脚本 / 图片可直接生效），改完源码切回预览即刷新，可与分屏视图配合边改边看。
  - **SQL 查询**（CSV / TSV / JSONL）：可开关的覆盖层——在当前视图上方打开，再点一次关闭并恢复底层视图，不顶替视图选中态。把当前文件导入临时 SQLite（不修改原文件），在 `t` 表上执行 SQL 过滤/排序/聚合；CSV/TSV 自动推断列类型与分隔符，JSONL 展平顶层字段、嵌套值保留 JSON 文本；最多显示 100–5000 行，可随时「重新导入」。只作用于临时副本，`ATTACH` / `DETACH` / `VACUUM` 会被拒绝（防止借 SQL 把数据写到任意文件）。
  - **表格视图**（CSV / TSV）：冻结表头与行号，拖动表头边缘可调整列宽；点击单元格直接编辑（Enter 确认并下移、Tab 换格、Esc 取消），支持撤销/重做。大表使用虚拟滚动，只渲染视口附近的行，百万行级数据也能流畅浏览；点击表头排序、顶部输入框筛选（只影响视图，不改原文件），右键表头可打开列统计（行数、空值、唯一值、数值 min/max/avg、最长值、疑似类型）。`Ctrl+滚轮` 可缩放表格（25%–800%），右下角锁图标旁显示当前比例，点击可选常用比例。
  - **数据工具**：`Ctrl+Shift+J` 打开 JSONPath 查询（支持 `$ . [] * ..`、切片、过滤与逻辑运算，JSON 结果可跳回源码行；YAML/TOML/INI 复用解析结果）；工具菜单可比较两个已打开文件（Myers 行 diff + JSON/YAML/TOML 的语义级差异），或对 JSON/JSONL 做 JSON Schema 校验（零依赖，错误可按路径跳转）。
- 设置 → 文件格式可按格式分组展开：每个格式单独配置编码、缩进、保存换行和默认视图，「通用文件格式」页提供总览表；修改后对当前同类文件立即生效。
- 代码视图支持自动换行开关（设置 → 编辑器与写作或视图菜单），默认关闭，长行横向滚动。缩进参考线默认关闭，可在设置 → 编辑器与写作 → 文件树与代码视图开启。Python 取色对齐 PyCharm：方法/属性调用用正文色，内置函数与关键字参数用橙色。
- **代码补全**（Ctrl+Space / Alt+/ 手动触发；设置 → 编辑器与写作三开关，「输入时自动弹出」默认关）：编辑器按格式给结构候选——JSON/JSONL 键、YAML 键、XML 标签/属性、INI/TOML 段/键——再叠加全文档词法候选与模糊匹配（前缀 / 驼峰 / 子串），只读与只读锁文件不启用；SQL 控制台（语法高亮）给方言关键词、库/表/视图与列候选（来自连接元数据，本地无索引），`表.` 或别名后自动出列，悬浮显示列类型/主键，DDL 与写库后自动刷新。
- 代码截图：代码/分屏视图右键 →「代码截图」，复制为图片或导出 PNG（底色与正文跟随当前代码主题，卡片框架跟随软件主题）。成品图只有代码卡片本身，无外圈背景；标题（文件名 · 行号）默认不画，可在子菜单勾选「带标题」，行号 / 圆角 / 输出倍率在设置 → 编辑器与写作 → 代码截图调整。
- 状态栏右下角提供只读锁定：默认解锁；点击后所有打开和之后打开的文件都变为只读，树编辑、代码/文本输入、表格单元格编辑、保存和格式化均被阻止，再点一次解锁恢复。
- 大文件、二进制、解析失败等顶部提示条右侧可点 `×` 关闭当前文件的提示；设置 → 通用设置可全局关闭“显示顶部提示条”。
- 图片文件默认显示图片视图，右下角视图菜单可切到二进制视图；按扩展名/文件头识别，直接预览上限 32 MB。图片视图支持 `Ctrl+滚轮` 缩放，点击 footer 比例可选自动适配或常用比例（25%–800%），双击恢复适配大小；超出视图时可拖动平移。其他含 NUL 或大量控制字符的文件（如 `.bin`）按二进制处理，只读十六进制视图超过 1 MB 只显示前 1 MB 并在顶部提示。
- 视频文件（mp4 / m4v / webm / mov / mkv，按扩展名与文件头识别）默认显示**视频视图**：播放器带原生控制条，打开不自动播放，可切到二进制/文本视图。播放走内置预览资源通道（拖动进度条按 Range 读取，不把整片读进内存）；解码由系统 WebView2 负责——H.264/AAC、VP9、AV1 可直接播，HEVC/H.265 需要系统装「HEVC 视频扩展」，解不了时给出原因并自动回到二进制视图。切标签或切视图自动暂停，关标签释放解码器。受单文件 100 MB 打开上限约束。
- 音频文件（wav / mp3 / ogg / oga / opus / flac / m4a / aac / weba，按扩展名与文件头识别）默认显示**音频视图**，可切到二进制/文本视图。图片 / 视频 / 音频的**默认视图固定为自己的媒体视图**：手动切到二进制或文本只影响本次会话，重开（含启动恢复上次会话）仍回到媒体视图。
- 未识别的扩展名按纯文本打开。
- 大于 10 MB 的文件切换为只读代码模式；大于 100 MB 拒绝打开。

## 编辑与文件

- 新建、打开、保存、另存为、保存全部、重新加载、关闭标签。
- 撤销/重做；内容恢复到原版后会自动清除“未保存”标记。
- 内容区查找栏：`Ctrl+F` 打开 IDEA 风格浮动查找栏，支持区分大小写、全字匹配、正则表达式、结果计数、上一个/下一个、`↑`/`↓` 或 `Enter`/`Shift+Enter` 跳转；代码视图高亮全部匹配，文本视图定位到匹配项。
- 快速切换面板：按 Ctrl + 反引号打开 IDEA 式“切换”弹窗，可按数字或点击进入主题、视图模式、编辑器字体、字号、缩进、布局、打开方式；数字键或点击应用，Esc 返回或关闭。
- 文件未编辑时，代码/文本视图保留磁盘原文格式；未修改直接保存也不会重排格式。
- 关闭有未保存修改的标签或窗口时确认；有 AI 会话正在进行、AI 后台命令仍在运行或终端正在执行任务时，关闭窗口会二次确认并按来源列出数量（「终止并关闭」）。空闲的终端提示符（没有命令在跑）不拦截。AI 后台命令作业结束、AI 创建的终端异常退出时会自动唤醒对应会话汇报结果，无需模型轮询等待。
- 自动保存开关：停止输入 1 秒后静默保存当前文件。
- 写作模式（`视图 → 写作模式` 或通用设置，仅纯文本与 Markdown 源码视图生效）：中文写作排版（楷体/宋体/仿宋、独立字号、暖黄/调暗纸色滤镜）、打字机滚动（光标行垂直居中）、段落聚焦（非当前段落淡出）、状态栏码字统计（今日/本次/每日目标，点击查看详情与速度）；「格式 → 小说排版」一键整理段落（去行尾空白、收敛连续空行、Markdown 语法行与代码块保护，纯文本可加段首全角缩进）；「工具 → 起名器」随机人名插入光标处、一键插入场景分隔符；纯文本支持「第X章/序章/番外」等章节大纲（卷/章层级 + 每章字数）。
- 阅读模式（`视图 → 阅读模式`、目录右键「作为书籍阅读」、md/txt/docx/epub 右键「阅读此文件」）：把一个目录变成一本可连续阅读的书——自动识别卷-章-节结构（文件即章 / 文件内切章 / 多级文档树，可手动覆盖章级），中文排版（宋体/楷体/微软雅黑/等线、字号 16–28、行高、页宽、段距、段首缩进、纸白/护眼/纯白/夜间主题）、进度按字数加权记忆（重扫后按 ID→标题→比例四级回退）、书签（`Ctrl+D`）、章内查找（CSS Custom Highlight，`Ctrl+F`）与全书搜索（`Ctrl+Shift+F`，带预算即时扫描可取消）、阅读统计（时长/连续天数/近 7 天柱状图）、文档树模式（点击任意标题渲染区间）、朗读（Windows 中文语音，句级高亮跟随、自动续章）、大章自动分块、连续滚动与分页开关。全程只读：不改源文件、不进会话文件列表、不建全文索引。
- 打开文件位置、复制文件路径/文件名。
- 状态栏消息中心：集中查看 AI 提问、审批与系统提示；打开即标记已读，点击可跳转会话或执行对应动作，清空后面板平滑收缩并保持贴住入口。
- 存储与清理（`设置 → 存储与清理`）：逐条显示本应用自己产生的缓存与数据占用（应用数据目录 / 当前工作区 `.cadt` / 系统临时目录里我们写的那部分），顶部三格汇总 + 「可释放缓存 / 用户数据 / 其他」占比条，格子数字含未登记条目，等于目录真实占用。**清除缓存**一键回收可再生的部分（运行临时副本、内嵌浏览器实例数据、界面浏览器缓存、会话搜索索引、运行与调试日志、AI 对话导出、模型配置表缓存、内置技能副本、系统临时文件、工作区工作日志）直接删除；**清除数据**按勾选处理，内容送回收站，「不可恢复」的条目（AI 会话记录、记忆、补丁库、定时任务、全部配置、界面状态）在确认框里逐个点名。正在使用的内嵌浏览器实例会自动跳过并标注；WebView2 相关的两项运行中被进程锁住，会排到下次启动前执行。支持**自动清理**：按时间间隔（每天 / 3 天 / 每周 / 每月）或缓存大小阈值（100 MB ~ 2 GB）任一满足即自动清缓存（启动后 2 分钟与运行中每 6 小时各检查一次；范围不含含网页登录态的浏览器实例数据与任何用户数据，完成后经消息中心提示）。
- 操作记录（`设置 → 操作记录`）：打开 / 保存 / 删除 / 重命名 / 移动 / 格式化、设置变更、标签 / 工作区 / 视图切换、插件启停、AI 审批与工具执行摘要等状态改变类操作按月存入本机 `activity/*.jsonl`（按动作大类 / 来源 / 关键字筛选，可导出 JSON / CSV、清空或关闭，保留 1–60 个月可调）。只记操作摘要，不记录文件正文与密钥；AI 可经 `app_control get_activity` 只读查询，帮用户回忆「刚才改了什么」。
- 拖入一个或多个文件时按落点分流：**编辑区**正常打开（多文件=多标签页）；**侧栏文件面板**复制到指定位置（目录行=该目录、文件行=父目录、空白区=工作区根）；**侧栏数据库面板**把 SQLite 库文件以只读加入当前工作区并展开，或导入连接配置文件（`db-connections.json` 同构）里的 MySQL/MariaDB/Redis 连接；**AI 面板**（含消息区）把文件作为附件放进当前会话输入区（图片/视频/文本按类型分派，可一次拖多个）。其他面板与窗口其余区域不响应拖放。支持文件对话框多选，也可以直接打开文件夹。
- 外部修改保护：文件被其他程序修改时，未编辑的标签自动重新加载（后台标签切回时重载，标签显示强调色圆点）；已编辑的标签不会被静默覆盖，保存时弹出冲突对话框，可选择重新加载（放弃自己的修改）、仍然覆盖或取消；自动保存遇到冲突会跳过并提示。
- 文件侧边栏（`Ctrl+B`）：列表视图（文件列表）为**扁平递归扫描**——打开了工作区就列出工作区下所有文件（含嵌套子目录），只打开单个文件时列出其所在目录及子文件夹的全部数据文件；目录数 / 深度 / 条目数有硬上限，超出时列表尾部给截断提示（可用过滤框缩小范围），不再出现「超过 200 个只能切文件树」；文件树视图按 IDE 风格懒加载目录。单击只选中，选中项为圆角高亮，连续多选合并为一整块（仅首尾圆角）；单击目录前的箭头可展开/收起，双击打开文件或展开/收起目录，`Ctrl+单击` 可多选文件/目录，`Shift+单击` 从上次锚点连续选择，`Ctrl+Shift+单击` 追加一段范围；选中单个文件或目录后可按 `F2` / `Shift+F6` 重命名，多选后可批量复制、剪切、粘贴。当前打开文件不再额外加背景高亮。缩进参考线默认关闭，可在设置 → 编辑器与写作 → 文件树与代码视图开启。文件树/列表默认每 3 秒自动同步一次，切回应用时立即刷新；窗口聚焦时由文件系统通知按变化目录即时局部刷新（内容没变不重渲染、滚动位置保持），目录 mtime 未变时跳过重读；可在设置 → 编辑器与写作 → 文件树与代码视图调整轮询间隔或关闭。切换标签页**不会**展开目录或滚动文件树（对齐 JetBrains：只更新当前行高亮），需要定位时点侧栏标题栏的靶心按钮「定位当前文件」；删除文件后就地摘除该行，不再整树重建，展开态与滚动位置都保留。折叠对象/数组显示带主题底色的 IDEA 式预览（浅色浅绿底、深色淡灰底）：对象显示首项键值对（如 `{"id": "..."...}`），数组显示 `[ N 个元素... ]`，预览与字段垂直居中，点击预览即可展开；展开行默认不显示项数，可在设置 → 编辑器与写作 → 文件树与代码视图开启「文件树显示对象/数组项数」；文件名过长时侧边栏显示横向滚动条，不再用省略号截断。
- 左侧工具条：IDEA 风格竖向工具窗口栏，文件树左边常驻显示；包含文件树开关、结构视图、内容搜索、视图/工具窗口“更多”、只读锁、主题、设置和关于。文件树开关与底部状态栏按钮状态同步。

- **Git 图谱**（底部面板新视图，参考 JetBrains Git Log）：左下活动栏点「Git 图谱」按钮，在底部面板（与终端 / 调试控制台 / 运行面板共用，高度可拖到窗口 85%）切到图谱。左栏 ref 树（HEAD / 本地分支 / 远程分支 / 标签 / Worktree，带「过滤分支…」搜索框，点分支即过滤到该分支），中栏带**泳道拓扑**的提交列表（泳道与弯入/弯出边在 Go 侧算好，前端渲染竖线 / 弧线 / 圆点；顶部「搜索提交」按 subject / sha / author 过滤），右栏提交详情（完整正文 + 作者行 + ref 徽章 +「在 N 个分支中」+ **本次变动文件树**）。提交行**右键菜单**：复制修订号 / 新建分支… / 签出修订 / Cherry-Pick / 将当前分支重置到此处…。详情面板也支持**签出 / cherry-pick / 重置（软 / 混合 / 硬对话框）**——都是用户主动点击、走确认弹窗（hard 明确警示丢工作区改动；签出被未提交改动挡住时弹强制/智能/不签出三选一，智能签出自动 stash 并恢复），只读模式下置灰。
- 右键菜单：标签页可关闭/关闭其他/全部/左侧/未修改、复制路径、在新窗口打开、重新打开关闭的标签页；侧边栏目录可新建常用文件（Markdown / TXT / Python / JavaScript / JSON / Go / Java / CSV / C++ / Vue），其余类型（TypeScript / HTML / CSS / SQL / Shell / PowerShell / 批处理 / Kotlin / Lua / YAML / XML / TOML / JSONL / INI / Properties）收进「更多」二级菜单，「文件…」「临时文件」（占位待实现）「目录…」置顶；右键菜单不放撤销 / 重做与展开收起目录（撤销走文件树聚焦时的 `Ctrl+Z` / `Ctrl+Y`）；文件和目录都可复制、剪切、粘贴、重命名、删除（移到回收站，`Delete` 键；已打开文件的标签会一并关闭）；粘贴到同名位置时会先给出“名称 - 副本”建议再确认；复制路径子菜单提供绝对路径、相对当前打开目录的路径（不带 `./`）和文件名；目录另有「结构化目录 → 复制 / 导出…」，导出时先弹出系统保存对话框选择路径（取消则不导出），生成与参考脚本一致的目录树（首行为当前目录名，忽略 `.git` / `__pycache__`，文件夹优先、自然排序）；代码/文本内容区可剪切复制粘贴、查找、格式化、重新加载、折叠，代码视图下另有「运行」（与 `F5` 同一执行链路）；标签页与文件树里的文件/目录都提供「用默认应用打开」（交给系统默认关联程序，不经过命令行，空格与中文路径安全）。

## 外观

- 界面主题只维护**深色 / 浅色**两套：深色以 IDEA Dark 为基底、浅色以 IDEA Light 为基底；编辑器配色独立于界面，可选 9 套**代码主题**（IDEA Dark、Darcula、Tokyo Night、IDEA Light、GitHub Light、Shiki（DeepSeek）、Newsprint 暖纸、Pixyll、Whitey），每套除语法 token 外还接管编辑器底色 / 行号槽 / 选区 / 缩进线——深色界面配浅色代码主题时编辑器区完整变浅（对齐 IDEA 的「UI 主题与编辑器配色方案分离」），默认「跟随软件主题」；旧版九套界面主题升级后自动迁移为对应组合。内置主题统一定义在 `frontend/src/core/themes.json`，插件可通过继承与变量覆盖扩展同类主题，示例见 `docs/plugins/examples/theme-pack/`。
- 内置字体：Inter、JetBrains Mono、Fira Code。
- 界面字体、编辑器字体、界面中文字体、编辑器中文字体可分别选择，并带实时预览。
- 固定键列与键列宽度可调。
- 编辑器字号 9–24，可用 `Ctrl+滚轮` 调整。
- 文件树字号 10–20（步进 0.5）可单独设置，只影响左侧文件列表/目录树。
- 窗口置顶默认关闭，可在通用设置开启。
- **编辑区收起**：内容区与 AI 面板之间的细条（或 `视图 → 收起编辑区`）可把编辑区位置整个让给 AI 助手，标签页保留不关闭；AI 面板关闭后编辑区自动还原。
- 所有设置本地持久化，统一存放在 `%APPDATA%\CandySweet\CaDt-DataLens\`：`config.json` 保存打开方式等后端配置，界面设置与 WebView2 数据在 `WebView2\` 子目录，AI 配置（模型/提示词/偏好）在 `ai-config.json`（localStorage 保留镜像），AI 会话在 `ai-sessions\` 子目录（每个会话一个追加式 JSONL + `meta.json`，图片在会话目录的 `images\` 下），会话搜索索引在 `ai-index.db`（可删除重建），应用数据模式的插件在 `plugins\` 子目录。

## 多文件

- **单窗口标签页**：类似代码编辑器的多标签体验，每个标签保留自己的视图、滚动位置和撤销历史。
- **多窗口**：每个文件使用独立窗口；适合并排对照多个文件。
- 在设置 → 通用设置 → “多文件打开”中切换。
